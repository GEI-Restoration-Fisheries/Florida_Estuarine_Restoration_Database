Florida Estuarine Restoration Database 

The Florida Estuarine Restoration Database is a comprehensive database of estuarine restoration projects compiled from multiple federal, state, and regional restoration programs. The database integrates project information into a standardized framework, allowing users to explore restoration activities using consistent classifications for habitats, restoration techniques, funding sources, project outcomes, and other key project attributes.

The Florida Estuarine Restoration Database was developed by the Gulf Ecosystem Initiative Restoration and Fisheries working group (https://www.nceas.ucsb.edu/impact-estuarine-habitat-restoration-fisheries-gulf), with the goal to improve the accessibility, consistency, and transparency of restoration information that is often distributed across numerous independent databases.

This GitHub repository serves as the official home for the database, including documentation, versioned data releases, metadata, and supporting materials.
